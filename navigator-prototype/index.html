Eligibility decisions: officers only

The system explains published criteria. It never decides.

Channel- and model-independent design

Candidates to compare before selection: hosted OpenAI and Anthropic models, and an open-weight model such as Llama or Qwen. No model testing has been done yet. In this prototype the language-model step is replaced by pre-written, catalogue-grounded replies.

What this prototype demonstrates (from the Round 1 answer pack)

  • Q30/Q32: question in Twi, English or a mix → retrieval from NJSMA catalogue → plain-language answer with sources → consented referral draft.
  • Q34/Q41: rule checks block uncited, out-of-date and eligibility-deciding answers; uncertainty or distress hands over to a person; channel-agnostic (WhatsApp, SMS, help point).
  • Q33: Efua's journey: tailoring query, criteria explained, officer reviews and decides.
  • Q30 activity 5/Q40: anonymised dashboard with small-number suppression, disaggregated by sex.
  • Q39: minimal data, explicit consent; sensitive questions optional; logs hold no names.

Not in this prototype

  • Real language model, Twi speech, real WhatsApp/SMS gateways, authentication, a database, Data Protection Commission-compliant storage. State lives in this browser only.
